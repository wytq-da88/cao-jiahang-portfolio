## 加载测量与限制

首页主图 186,679 字节，fetchPriority=high；实际浏览器确认已加载。首页没有原始高清图片请求节点和 video 元素，其他展示图延迟加载。全部 22 张网页展示图总计 3,912,948 字节；5,113,074 字节的原视频仅在点击后进入播放器。

可用浏览器读取层不提供 navigator / Performance API，未获得 Lighthouse、LCP 或帧率。采用可用的 curl 8.21.0 标准传输计时：Windows 本机回环，未限速、服务器未压缩，首页和主图各三次均 HTTP 200。首页文档 37,864 字节，传输约 3.0—3.6ms；主图约 2.8—4.3ms。它们仅表示本地传输，不代表公网加载、真实手机速度或 Core Web Vitals。

测量原始数据见 `03-transport-timing.json`，首屏 DOM 验证见 `03-loading-local.json`。性能指标含义参考 [MDN 导航与资源计时](https://developer.mozilla.org/en-US/docs/Web/Performance/Guides/Navigation_and_resource_timings)。实际手机硬件、低端设备帧率和 Safari 尚未测试。
