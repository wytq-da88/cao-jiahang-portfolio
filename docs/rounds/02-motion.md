# 第二轮：产品叙事与可打断的交互

完成于 2026-10-06，基于第一轮 `1094d69`。

## 已实施的变化

- 根据用户“更高级一点”的反馈，扩大壁时产品占比，减少边框装饰；标题改用本地托管的 Noto Serif SC 500 子集，正文保留系统无衬线字体。移动端先展示作品，再展示项目信息。
- 应用 apple-design 的单一视觉主角、短标题、图文分章和克制反馈方法：壁时从全景、细节、推导进入 CMF、交互与系统，首屏正文始终可见。图片视差最多 28px，链接反馈约 200ms。
- 桌面精细指针且宽度至少 960px 时启用 Lenis；手机使用原生滚动。原生锚点 URL 与焦点同步，键盘滚动可打断，返回操作不锁死滚动。
- 原图链接增强为原生 dialog 画廊；保留原图入口、前后切换、方向键、Escape、Tab 循环及关闭后焦点恢复。
- 手机菜单支持展开状态、首次入口焦点、Escape 恢复与选择后收起。
- 视频点击后才创建播放器；封面、图注与原文件链接常驻，错误时可重试。明确保留 AI 概念视频的来源水印。
- “减少动态”开关会关闭平滑滚动和视差；系统偏好在运行时变化也会清理已启动的动态。

## 验证与修正

- 功能测试先失败后实现，最终 22/22 通过；静态构建成功。
- 1440×900 实际浏览器：无横向溢出；手动减少动态后 `data-reduced-motion=true` 且 Lenis 清理，恢复后为 false 且 Lenis 重新启用。系统偏好运行时变化由功能测试覆盖。
- 390×844 实际浏览器：菜单展开聚焦“作品”，Escape 回到“打开菜单”，选择“壁时”后菜单收起并进入案例。案例先图后信息，无横向溢出。
- 画廊实际 Tab 循环为“关闭→上一张→下一张→原图→关闭”；Shift+Tab 反向循环。Escape 后恢复所点击的细节图入口。手机弹窗高 666.2px，小于 844px 视口。
- 视频初始不存在 video 元素；点击后实际播放，readyState=4、currentTime=18.0s、duration=40.13s，无媒体错误。这是本地播放证据，不是实物演示或性能分数。
- 实际浏览器发现 Lenis 已读取 CSS 滚动间距，额外 offset 重复累计。去掉重复值后 #form 章节顶部由约 352px 修正为约 176px。
- 原图的网格最小尺寸曾超过弹窗，修正 min-height 和 contain 后，桌面图像与舞台同为 585px，保持完整比例，控件不覆盖图片。捕获证据前检查网络与图像完成状态。
- 原生 dialog 在最后一个链接后允许 Tab 离开页面内容；增加首尾焦点循环，新增回归测试先失败再通过，并完成实际浏览器复测。
