# 2026-10-07 个人作品集参考与局部优化

用户明确要找优秀的个人作品集网站，并优化当前站点。沿用已确认的东方器物方向，本轮完成三个局部调整：

1. **首屏展示**：壁时整体、细节、场景三个手动视角。加载时保留当前图，失败可重试；键盘焦点留在按钮。无自动轮播，无新增运行时依赖。
2. **作品入口**：四项目编号目录直接进入案例；图片与年份沿用现有资料。
3. **案例阅读**：四案例新增设计问题、核心选择、完成内容；“开始阅读”到项目简述并获得焦点。必要的概念验证边界明确保留。

参考取舍见 [作者站点与适配方法](../../references/个人作品集参考-2026-10-07.md)。代码自行实现，作品素材未改。
